# paygeo-wallet-flow

Self-contained demo widget: send money to a phone number, collect it as cash at an ATM with a one-time code.

Single file: `index.html` (inline CSS + JS, no external requests). Copy for both languages lives in the `COPY` object at the top of the script.

Query params: `?lang=es`, `?step=3`, `?pause=1` (disables autoplay).
